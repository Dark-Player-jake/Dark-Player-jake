### Wie ich arbeite

- **Fertig statt halb fertig:** Abnahme am echten Gerät, bevor etwas als erledigt gilt.
- **Local-first:** Daten und Modelle bleiben auf dem Rechner, wo es sinnvoll ist.
- **Getestet:** Automatische Tests und echte Sichtprüfung gehören zum Bauen dazu.
